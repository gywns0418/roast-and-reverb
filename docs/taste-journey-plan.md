# 취향 여정 기획 (2026-11-13)

## 한 줄 정의

**마신 커피를 기록할수록 "나만의 커피"가 또렷해지는 곳.** 월픽은 매달 다른 로스터리로 그 취향을 확인해 보는 실험 무대다.

## 누구를 위한가

커피에 진심인 사람. 집에서 직접 내려 마시고, 원두를 고르는 데 시간을 쓰고, "왜 이번 원두는 좋았지?"를 궁금해하는 사람.

- 지금의 불편: 좋았던 원두를 기억하지 못한다. 기록은 남겨도 다음 원두를 고를 때 쓰이지 않는다. 월픽은 매달 바뀌는데 어떤 걸 골라야 내 취향인지 모른다.
- 바라는 결과: 기록이 쌓일수록 "나는 고소하고 산미 적은 쪽을 다시 찾는다" 같은 문장을 스스로 확인하고, 다음 원두를 덜 헤매며 고른다.

## 핵심 고리

```
한 잔 기록 ─→ "다시 마시고 싶나요?" 판단
    ↑                     ↓
월픽에서 새 로스터리 ←─ 나의 취향 (좋았던 맛·로스터리·추출)
```

1. **기록**: 한 줄 감상 + 선택 판단 3단계(다시 마시고 싶어요 / 괜찮았어요 / 내 취향은 아니었어요). 판단은 비워 둘 수 있다.
2. **나의 취향**: 판단한 기록만 모아 "자주 좋았던 맛", "맞지 않았던 맛", "다시 마시고 싶었던 커피", "만나 본 로스터리"를 보여 준다. 숫자는 내가 남긴 기록 수뿐이다.
3. **월픽에서 확인**: 이번 달 원두 중 판매처 컵노트가 내 "좋았던 맛"과 겹치는 원두에 "내 취향과 닮음" 표시. 이유(겹친 맛)를 함께 보여 준다.
4. **다시 기록**: 월픽에서 고른 원두를 마시고 기록하면 고리가 한 바퀴 돈다. 이번 달 로스터리를 기록했는지 "로스터리 여정"으로 보여 준다.

## 북극성 지표

**판단을 남긴 한 잔의 수**(월별). 기록만 하는 것보다 "다시 마실지"를 남긴 잔이 취향을 만든다.

보조 지표: 월픽 로스터리를 기록한 달의 수, "내 취향과 닮음" 원두를 연 횟수. (지금은 서버가 없어 기기 안에서만 볼 수 있다.)

## 이번에 만드는 것

| 기능 | 위치 | 원칙 |
|---|---|---|
| 판단 3단계 | 저장 전 카드, 기록 상세 | 선택 사항. 추측해서 채우지 않는다 |
| 나의 취향 화면 | 새 메뉴 "나의 취향" (`/taste`) | 내가 판단한 기록만 근거. 근거 잔 수를 함께 표시 |
| 판단 안 한 기록 바로 정리 | 나의 취향 화면 | 지난 기록에 버튼 한 번으로 판단 추가 |
| 월픽 "내 취향과 닮음" | 월픽 카드 배지 + 필터 칩 | 판매처 컵노트와 내 좋았던 맛의 겹침만 사용. 맞지 않았던 맛과 겹치면 제외 |
| 로스터리 여정 | 나의 취향 화면 | 기록에 적은 로스터리 이름만 센다 |
| 취향 카드 공유 | 나의 취향 화면 | 내가 누를 때만 문장을 복사하거나 공유. 서버로 보내지 않는다 |
