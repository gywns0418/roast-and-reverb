# 색상 대비와 시각 안내 — 2026-11-01

- 첫 화면과 도움말의 사용 흐름을 자체 SVG 그림(커피잔/펜, 헤드폰/음표, 보관함)과 실제 텍스트 3단계로 설명. 음악은 선택이라는 점, 저장 전 확인, 기기 보관/백업을 명시.
- 원두 정보 그래픽에 이름·원문 산지·품종·가공·향미의 접근 가능한 설명 추가. 정보가 없으면 미기록으로 유지. 실제 상품 사진으로 표시하지 않음.
- 사용자가 등록한 원두 사진의 빈 alt/숨김 제거(보조 썸네일은 중복 장식으로 제외). 빈 기록 소개 사진에 서비스 연출 이미지 설명 추가.
- 인접 텍스트와 의미가 겹치는 안내 SVG와 반복 브랜드 연출 사진은 장식으로 처리. 모든 사진에 동일한 alt를 무조건 반복하지 않음.
- 저대비 보조문구, 월픽 가격/재고/시리즈 부제, 하단 링크, 입력 경계 개선. 판매처 향미 HEX 팔레트는 그대로 보존하고 글자색을 분리.
- 전역 sr-only 유틸리티 추가. 화면 읽기용 단계 텍스트와 폼 레이블을 시각적으로 중복하지 않음.

기준: [WCAG 2.2 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [WAI 이미지 대체 텍스트 판단](https://www.w3.org/WAI/tutorials/images/decision-tree/).

검증 범위: 97 frontend tests 및 Vite build 통과. 홈/도움말/월픽/첫 기록 화면의 실제 DOM 색상·배경으로 간이 대비 검사, 원두 설명/그림 안내 접근성 트리 및 모바일 줄바꿈 확인. 이는 전체 서비스 WCAG 준수 인증이 아니며 동영상·사용자 사진 내부의 픽셀 대비나 모든 상호작용 상태의 전수 검사를 뜻하지 않는다.
