# R&R 페어링 엔진 v1

2026-10-13 / Asia/Seoul. 무료로 기기 안에서 실행하는 커피 × 음악 분석 및 개인 선호 학습 엔진이다.

## 현재 구현과 한계

학습된 대형 언어 모델이나 음원 분석기가 아니다. 커피 맛 노트·로스팅·직접 평점과 음악 장르·태그·감상을 개발자가 정의한 4개 의미 특성(밝기·깊이·부드러움·공간감)에 연결한다. 직접 입력한 0~5 평점은 해당 축의 텍스트 추정보다 우선한다. 곡명/아티스트/원두명만으로 음악 특성이나 향미를 추정하지 않는다. 양쪽 정보가 부족하면 저장을 진행하지 않고 입력을 요청한다. 미지의 축을 측정값으로 채우지 않는다.

기본 점수는 공통 특성의 1-절대차 평균 × 100인 **특성 유사도**다. 이 점수는 객관적 품질, 만족 확률, 검증된 추천 정확도가 아니다. 수동 사전과 가중치는 첫 버전이며 부정문, 복합적 감상, 장르 경계와 문맥 해석은 제한적이다. 일반 rock과 post-rock을 분리했다. 기존 페어링 예시 기록은 새로운 엔진의 분석 결과로 소급 변경하지 않는다.

## 선호 학습

페어링 상세의 잘 어울려요/조금 아쉬워요를 1/0 학습 레이블로 사용한다. 입력은 바이어스와 4개 특성 유사도다. 온라인 로지스틱 회귀를 학습률 0.25, 약한 가중치 축소 0.002로 한 단계 갱신한다. 초기 가중치는 0이며 5건 이전에는 유사도만 표시한다. 5건부터 개인 선호 추정을 표시하며 학습 수와 점수 종류를 함께 표시한다. 소량 피드백 모델이므로 캘리브레이션된 확률이나 일반화 정확도를 보장하지 않는다. 부족한 축은 모델 입력에서만 중립 0.5를 사용하며 근거에는 미기록 상태를 유지한다.

localStorage rr-pairing-preferences-v1에 가중치/학습 수/페어링별 투표를 한 번에 저장한다. 같은 페어링의 중복 학습을 거절하고 새로고침 뒤에도 유지한다. 기기/브라우저 단위 모델이며 계정 간 서버 동기화는 제공하지 않는다. 다른 사람이 같은 브라우저를 쓰면 기기 모델이 공유될 수 있다. 기록 문장이나 개인 원본을 외부 모델 API에 전송하지 않는다. 브라우저 저장소 삭제 시 모델은 초기화된다.

## API와 저장

pairingApi.analyze는 기본 R&R 로컬 엔진을 명시적으로 호출한다. 실제 서버 모드의 선택지에서 engine:claude를 선택했을 때만 기존 /pairing/analyze를 호출한다. Claude 오류를 로컬 성공으로 대체하지 않는다. aiReason에 버전/근거/특성/정보량/분석 당시 학습 수를 JSON으로 보존하고 상세에서 읽기 쉬운 카드로 표시한다. 페어링 저장은 기존 회원 소유권 API를 유지한다. 자연어 구조화는 별도 기능이며 Pages의 고정 예시는 버튼과 안내에 명시한다.

## 검증

프론트 19개 테스트: 입력에 따른 다른 점수, 빈 정보 거절, 0 평점 보존, 미기록 축, 직접 평점 우선, 장르 경계/기록 문구 오탐 방지, 학습 방향, 중복 투표, 5건 경계와 원문 색상 필터 검사. 이 검사는 동작 검증이며 사용자가 실제로 좋아하는지 평가한 추천 정확도 실험은 아니다. 브라우저에서 분석/저장/근거/피드백/새로고침 후 중복 차단과 모바일 렌더링 확인.
