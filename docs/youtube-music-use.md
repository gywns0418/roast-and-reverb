# YouTube 음악 재생과 개인화 범위 (2026-10-18 확인)

기본 한국 선곡 5곡은 아티스트·유통사의 공식 업로드이며 저작권 무료 음원이 아니다. 공식 임베드 제공과 음원 복제·판매 권리는 다르다. 현재 앱은 음원을 내려받거나 재가공하지 않고, 사용자 선택 후 공식 YouTube 플레이어를 표시한다. 동영상·광고·출처·기본 컨트롤을 가리지 않으며 재생 자체를 과금하지 않는다. 향후 유료화에서도 YouTube 시청을 유료 권한으로 판매하지 않아야 한다. 개별 권리 분쟁이나 모든 지역의 이용 적법성을 보증하는 검토는 아니다.

- [YouTube 개발자 정책](https://developers.google.com/youtube/terms/developer-policies): III.F.3 재생 과금·추가 시청 조건 제한, III.G 상업 이용 조건, 백그라운드 플레이어 제한.
- [공식 플레이어 문서](https://developers.google.com/youtube/player_parameters): 재생목록·인라인 재생, 최소 플레이어 크기. 사용자 선택 전 플레이어를 로드하지 않는다. 화면 밖/비활성 탭에서는 플레이어를 해제한다.
- [공식 API 변경 이력](https://developers.google.com/youtube/data/revision_history): 시청 기록/나중에 볼 동영상 목록은 API로 접근할 수 없다. Google 로그인은 YouTube Music 청취 기록 동의나 연동이 아니다.

대안은 R&R에 실제 보관한 음악을 고르는 ‘내 음악’과 공개·일부 공개 재생목록 링크를 직접 넣는 ‘내 플레이리스트’이다. 자주 듣는 순위를 추측하지 않는다. 새 Google 권한·쿠키·비공식 API를 요구하지 않는다. 재생목록 링크는 계정별 이 기기 저장·백업·연결 해제를 지원하며 서버 동기화나 계정 OAuth 연결로 표시하지 않는다.
