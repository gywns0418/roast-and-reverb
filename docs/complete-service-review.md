## 실제 바꾼 화면

- 소개/오늘의 한 잔/기록 목록: 앞선 간소화 구현을 통합한다.
- 기록 상세: 날짜와 감상 → 직접 고른 음악 → 펼쳐 보는 추출 정보 → 다음 기록. AI/컬렉션 연쇄 조회와 기본 페어링 영역 제거. 기존 생성 연주는 읽기 전용 기존 플레이어로 유지.
- 기록 수정: 이름/날짜/감상만 먼저 표시. 추출과 음악 변경은 선택적으로 펼침. 숫자 0을 포함한 기존 평가, 추출 조건, 판매처와 관찰 맛, 음악 보존을 회귀 검사.
- 원두 탐색: 큰 홍보/분류·색상·비교·수입 UI 대신 시리즈 선택/검색/판매가능 필터/가격·컵노트 카드. native 상세창·Escape·초점 복귀. 기존 커스텀 월픽 노트와 관심 자료는 archive/monthly에서 보존하며 자동 수집 데이터/ID는 그대로 사용.
- 음악 목록/상세: 곡·날짜·감상 중심, 과도한 아트워크·별도 페어링/소장 조회 제거.
- 설정: 저장 위치/백업/음악/원두/도움말/개인정보 위주. 기존 도구는 보관함의 접힌 두 그룹으로 이동. 기존 URL과 저장 구조 유지.
- 백업: 내려받기 → 파일 선택 → 항목 교체 확인. 원래 검증·롤백·개인자료 제외 규칙 유지.
- 원두 관리: 파일 연결을 접어두고 기본 관리와 추가 중심. 추천 홍보 제거.
- 도움말: 소개와 실제 한 줄 기록 순서에 맞게 전면 재작성.
- 인증 4개 화면: 명확한 로그인/가입 표현, 체험 모드에 작동하지 않는 입력폼 노출 제거. 복구 미구현 페이지의 무의미한 이메일 입력 제거. 실제 서버 실패를 성공으로 바꾸지 않음.
- 보관 도구 전체: 공통 읽기 폭/제목/간격/44px 조작/1열 패널/장식 축소 스타일 적용. 보조 도구의 모든 내부 기능을 새로 구현한 것은 아님.

## 배포를 구분

GitHub Pages 운영 루트(main)와 개발(dev)은 브라우저 체험 모드다. 회원 서버 운영이 아님. 이번 Railway 상태 읽기는 UNAUTHORIZED / requires reauthentication으로 실패해 운영 서버 상태/회원 저장을 검증할 수 없었다. 같은 승인 거절을 반복하거나 대체 서비스/유료 배포로 우회하지 않는다. 이 한계는 최종 보고에도 명시한다. PR/CI/운영 배포 최종 결과는 continuity 마지막 기록과 원격을 따른다.
