GitHub Pages는 정적 호스팅이므로 상시 백엔드·비밀 키 기반 외부 AI·계정 동기화를 제공하지 않는다. GitHub Actions를 API 서버로 사용하지 않는다. 외부 공개 음악/모델/상품 자료는 사용자 요청에 따라 해당 제공자에서 받을 수 있으므로 모든 네트워크 요청이 GitHub만을 향한다는 뜻은 아니다.
