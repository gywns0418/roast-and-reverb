# 디자인 개선 제안 — 기존 배색 보존

사용자 확정: 전체 색상 교체가 아니라 기존 색 안에서 소수의 강조를 원한다. 이번 운영 변경은 색상 복구와 필터의 작은 포인트에 한정한다. 아래 항목은 개선 제안이며 아직 사이트 전체에 적용하지 않았다.

| 우선순위 | 개선 대상 | 제안 | 확인 기준 |
| --- | --- | --- | --- |
| 1 | 월픽 카드 정보 | 분류→원두명→컵노트→중량/가격→상세/관심/비교 순서와 정렬을 통일 | 같은 위치에서 필요한 정보를 비교할 수 있음 |
| 2 | 필터 영역 밀도 | 검색·분류·색상·판매 조건을 명확한 행으로 정렬하고 설명은 짧게. 분류/색상 필터를 숨기거나 없애지 않음 | 첫 화면에서 조건과 결과수를 찾고 개별 해제 가능 |
| 3 | 버튼 위계 | 화면의 주 작업 하나만 기존 녹색 채움. 관심·비교·도움말은 가벼운 텍스트/아이콘과 상태 표시 | 중요한 행동과 보조 행동의 시각적 경쟁 감소 |
| 4 | 글자·간격 | 제목24~28, 본문15~16, 보조13px을 기준으로 계층/행간/8px 간격 단위를 정리 | 모바일 줄바꿈·200% 확대·대비·포커스 확인 |
| 5 | 모바일 탐색 | 결과수와 적용 조건 요약, 필터로 돌아가는 이동 수단을 제공. 큰 필터 전체를 고정하지 않음 | 원두를 보고 조건을 바꾸는 왕복이 쉬움 |

## 작업 방향
월픽과 기록 작성 두 대표 화면에서 기존 색상을 사용한 ‘정보 밀도 중심’과 ‘시각 위계 중심’ 시안을 먼저 비교한다. 메뉴/데이터/필터 기능은 유지하며, 효과가 확인된 규칙을 다른 화면으로 확장한다. 가짜 시음/청취/후기 정보로 화면을 채우지 않는다.

## 플러그인
- Product Design: 연결 가능한 미설치 후보 확인. 실제 URL의 사용자 흐름 점검 및 비교 가능한 프로토타입이 현재 요청과 가장 잘 맞는다.
- Figma: 연결 가능한 미설치 후보 확인. 시안·컴포넌트·Auto Layout·변수로 정밀하게 관리할 때 유용하다.
- 추천만 했으며 설치/연결을 완료한 것으로 간주하지 않는다. 개인 기록·백업·계정 정보는 디자인 자료로 전달하지 않는다.

## 근거
- [NN/g 시각 위계](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/): 크기·대비·구획을 통해 중요한 정보를 우선 인식하도록 구성.
- [NN/g 점진적 공개](https://www.nngroup.com/articles/progressive-disclosure/): 보조 정보의 복잡도를 관리. 이 서비스의 핵심 분류/색상 필터를 숨기라는 의미로 적용하지 않음.
- [Figma Auto Layout](https://help.figma.com/hc/en-us/articles/5731482952599-Toggle-on-auto-layout-in-designs): 내용/화면 크기에 맞춘 배치 관리.
- [Figma 변수](https://help.figma.com/hc/en-us/articles/15339657135383-Guide-to-variables-in-Figma): 기존 색상·간격·상태를 규칙으로 관리해 임의 재도색을 방지.
