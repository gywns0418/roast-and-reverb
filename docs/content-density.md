# 콘텐츠가 채워지는 화면 — 2026-10-30

사용자 보완 요구: 기능은 단순해도 화면 자체는 꽉 찬 느낌이어야 한다. 월픽 복구 후속으로 공통 화면 폭·구획·여백과 핵심 화면 콘텐츠 배치를 조정했다. 별도 feature/content-density는 main에서 분기했고 최신 dev는 main에 포함되어 있다.

- 공통 본문을 최대1560px까지 사용하고 헤더/본문/푸터 간격을 조정. 제목을 읽기 쉬운 크기로 유지.
- 월픽 제목과 소개를 하나의 색면으로 묶고, 세 시리즈와 검색/관심/구매 필터를 촘촘하게 연결. 원두 그래픽을 카드 옆으로 이동해 실제 설명·가격·저장·비교를 처음부터 보여준다. 데스크톱3열/큰화면4열/모바일1열. 버튼 터치영역44px 유지.
- 기록이 없는 첫 진입은 기존 커피×음악 브랜드 이미지와 시작 안내를 제공한다. 실제 소비·취향·청취 기록을 생성하지 않는다. 데스크톱에서는 소개와 기존 FirstCup 입력을 나란히 배치하고, 모바일은 소개→입력으로 이어진다. 기존 기록이 있으면 해당 목록을 그대로 사용한다.
- 설정은 데스크톱2열로 배치. 기존 기능/메뉴/저장 키/관심/월픽3시리즈/개인노트/판매처 출처는 보존.
