필수 저장

로그인 토큰(roast-reverb-user), 체험 일지(roast-reverb-demo-v1), 기록 선택, 초안·원두·개인 취향(rr-discovery- 등), 관심 원두(rr-monthly-favorites-v1), 추천 선호(rr-pairing-preferences-v1), 쿠키 선택(rr-privacy-choice-v1)을 localStorage에 보관할 수 있습니다. 자료는 삭제하기 전까지 해당 기기에 남습니다. 버전에 따라 제공하지 않는 항목도 있습니다.

사용자가 연결한 원두 파일의 읽기 핸들은 IndexedDB(rr-private-bean-files)에 보관하며 원본 파일 자체를 업로드하지 않습니다. 의미 모델을 실행하면 모델 파일이 Cache Storage에 남을 수 있습니다. 브라우저의 사이트 데이터 관리에서 캐시까지 지울 수 있습니다. Google 인증을 실행할 때 임시 세션 쿠키와 최대 5분짜리 확인값을 사용합니다.

선택적 외부 재생

YouTube 외부 재생은 기본 차단합니다. ‘쿠키 설정’에서 허용하고 직접 재생해야 연결됩니다. youtube-nocookie.com을 사용해도 IP·기기 정보 전송이나 외부 저장이 전혀 없다는 뜻은 아닙니다. Google 로그인 SDK도 ‘Google 연결 준비’를 누른 뒤에 불러옵니다. 광고·방문 통계 SDK는 넣지 않았습니다. 외부 서비스의 처리는 Google 개인정보처리방침을 확인하세요.

선택 변경과 삭제

서비스 화면 아래 ‘쿠키 설정·개인정보 삭제 요청’에서 필수만 사용하거나 외부 재생 허용을 바꿀 수 있습니다. 거부해도 기록 기능을 이용할 수 있습니다. 필수 저장 차단은 브라우저 설정에서 할 수 있으나 기록 저장·로그인 유지가 제한됩니다. 브라우저 사이트 데이터 삭제는 서버 계정이나 외부 서비스에 이미 전달된 자료를 삭제하지 않습니다.
