쿠키정책

현재 운영은 GitHub Pages 기기 기록장입니다. 회원 서버·Google 로그인·외부 AI API를 사용하지 않습니다. 기록·설정은 브라우저에 저장하며 기기 간 이동은 백업 파일로 합니다. 이전 Railway 계정 자료는 자동 이전되지 않으며 개인정보 문의처로 권리를 요청할 수 있습니다.

시행일: 2026년 11월 1일

필수 저장

기기 일지(roast-reverb-demo-v1), 기록 선택, 초안·원두·개인 취향(rr-discovery- 등), 관심 원두(rr-monthly-favorites-v1), 추천 선호(rr-pairing-preferences-v1), 쿠키 선택(rr-privacy-choice-v1)을 localStorage에 보관할 수 있습니다. 자료는 삭제하기 전까지 해당 기기에 남습니다. 버전에 따라 제공하지 않는 항목도 있습니다.

사용자가 연결한 원두 파일의 읽기 핸들은 IndexedDB(rr-private-bean-files)에 보관하며 원본 파일 자체를 업로드하지 않습니다. 의미 모델을 실행하면 모델 파일이 Cache Storage에 남을 수 있습니다. 브라우저의 사이트 데이터 관리에서 캐시까지 지울 수 있습니다. 현재 사이트에서는 Google 인증 쿠키를 설정하지 않습니다.

선택적 외부 재생

YouTube 외부 재생은 기본 차단합니다. ‘쿠키 설정’에서 허용하고 직접 재생해야 연결됩니다. youtube-nocookie.com을 사용해도 IP·기기 정보 전송이나 외부 저장이 전혀 없다는 뜻은 아닙니다. 현재 사이트에서는 Google 로그인 SDK를 불러오지 않습니다. 광고·방문 통계 SDK는 넣지 않았습니다. 외부 서비스의 처리는 Google 개인정보처리방침을 확인하세요.

선택 변경과 삭제

서비스 화면 아래 ‘쿠키 설정·개인정보 삭제 요청’에서 필수만 사용하거나 외부 재생 허용을 바꿀 수 있습니다. 거부해도 기록 기능을 이용할 수 있습니다. 필수 저장 차단은 브라우저 설정에서 할 수 있으나 기록 저장이 제한됩니다. 브라우저 사이트 데이터 삭제는 서버 계정이나 외부 서비스에 이미 전달된 자료를 삭제하지 않습니다.
