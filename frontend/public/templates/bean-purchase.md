# 구매 원두 기록 양식

구매한 원두는 연결된 beans.md에 아래 구조로 추가합니다. 포장이나 판매처에 적힌 사실만 기록하며 모르는 항목은 비웁니다.
추출 레시피와 직접 마신 감상은 서비스의 노트 카드에 따로 남깁니다.
사진을 보내주시면 읽을 수 있는 내용만 정리합니다. 흐리거나 보이지 않는 항목은 추측하지 않습니다.
포장 사진은 진열장의 해당 원두에서 ‘이 원두의 포장 사진 더하기’로 연결할 수 있습니다.
이미지 파일명 자체가 사진을 서버에 업로드하거나 브라우저 파일 접근 권한을 부여하지는 않습니다.

아래 코드 블록은 작성 예시라 자동 가져오기에서 제외됩니다. 실제 기록은 코드 블록 바깥에 작성합니다.

```markdown
## 구매 원두

### 원두 이름
- 상태: 보유
- 구매 날짜:
- 구매 용량:
- 로스터리:
- 원산지:
- 농장:
- 생산자:
- 품종:
- 가공 방식:
- 고도:
- 로스팅 포인트:
- 로스팅 날짜:
- 컵노트:
- 이미지 파일:
- 남은 양:
```

같은 원두도 로스팅 날짜가 다른 구매분은 별도 항목으로 남길 수 있습니다.
원두 자료와 포장 사진은 현재 이 기기의 계정별 저장 자료입니다. 기기 자료 백업에 함께 포함되며 다른 기기로 자동 동기화되지 않습니다.
